# AI Agent 新手 Starter（Claude 或 ChatGPT 都能用）

給一個只用過網頁版 AI 的人，**最少動作**得到一個已經調好、認識他、有人格、有記憶的私人 AI 夥伴。

> **跟網頁 AI 最大的差別**：以前的 AI 只能在對話裡「生成一個表格給你看」，你還得自己複製貼上；agent 只要你允許，能**自己上網幫你找東西抓回來、直接產生 Excel/Word/PDF 檔、也能直接打開修改你現有的檔案**——很多東西都能真的「落檔」存下來。
>
> ⚠️ 最容易忘記的一件事：**有任務時先想到問它，別下意識自己開瀏覽器。**（想找財報？直接叫它「幫我找 X 公司財報抓下來存檔」就好。）

流程刻意分兩段：**先安裝 → 開一個新對話 → 再個人化**（新對話讓剛裝的指令正確載入，也順便學到「開新對話才生效」這個常用概念；**App 全程不用關**）。

## 你有哪個訂閱？兩條路一樣走

| 你有 | 下載 | 進去點哪裡 |
|---|---|---|
| **Claude**（Pro/Max） | <https://claude.ai> 桌面 App | **Code** 分頁 → New session |
| **ChatGPT**（Plus/Pro） | <https://chatgpt.com/download> 桌面 App | **Codex** 分頁 → 新對話 |

> 🪟 **Windows ＋ Claude 的人，先做這一步再往下：安裝 [Git for Windows](https://git-scm.com/downloads/win)，裝完把 Claude 完全關掉再打開。**
> 這是 **Claude Code 自己的硬性需求**（它用 Git 來隔離每個 session），不是我們這個 starter 要求的。沒裝的話，你**選完資料夾就會跳出「Git is required」**——那個下載連結會把你帶到 github.com，很多人因此以為「要先申請 GitHub 帳號」。**不用帳號、不用註冊，就是裝一個工具程式，一路按下一步即可。**
> Mac 通常已內建 Git，直接往下走就好。**ChatGPT／Codex 路線沒有這個需求。**

兩邊都**不用碰終端機**，之後的步驟完全相同。（2026-07 起 Codex 已併進 ChatGPT 桌面 App，沒有獨立的 Codex App。）

## 怎麼用

**① 安裝**
1. 依上表裝好 App 並登入。
2. 開新對話。
   - 它可能會跳出 **Open folder（選擇資料夾）**，預設就是你的家目錄 `~/`——**直接用預設、按確認即可**（我們的設定裝在使用者層，開哪個資料夾都不影響）。
   - 接著可能有**一連串確認/同意**畫面，照著按下一步。
3. **先切權限模式（Claude 必做，這步省下來會很痛）**：看畫面**左下角**的權限按鈕（或按 `Shift+Tab` 切換），從預設的 **Auto** 切到 **Accept Edits**。
   > 為什麼：Claude 把自己的設定資料夾 `~/.claude/` 列為**受保護路徑**。在 **Auto** 模式下，寫進去的動作會交給一個安全分類器審核、**有可能被默默擋掉**——你不會看到任何詢問視窗，只會覺得「怪怪的、好像沒裝成功」。切到 **Accept Edits** 之後它會**明確跳出來問你**，你按允許就好。
   > （模式只有 `Manual` / `Accept Edits` / `Auto` 三個，沒有「Auto-accept」。ChatGPT/Codex 沒有這個設定，跳過這步。）
4. 貼下面這段話、按 Enter：

> 請用 curl 取得 `https://raw.githubusercontent.com/DasunLin/ai-agent-starter/main/SETUP.md` 的原始內容（不要用會摘要的方式），然後完全照著它幫我設定。我是新手，請一步步帶我。

> 安裝過程它會**跳出「要不要允許執行/寫入」**——正常的（它正準備幫你建檔案），按 **Allow / 允許 / Yes**。若選項裡出現 **「Yes, and allow Claude to edit its own settings for this session」**，**選那個**，後面就不會一直問你。

> 🍎 **Mac 專屬**：安裝**過程中**若跳出要你安裝「命令列開發者工具 / Xcode」的視窗——**按「不現在」，這個不用裝**。跟它說一句「不要用 git，改用 curl」就會繼續。
> （🪟 Windows 那個「Git is required」是**不一樣的東西**、發生在更早的選資料夾階段，那個**要裝**，見上方前提。）
>
> 兩種情況都一樣：**你不需要 GitHub 帳號、不需要註冊任何東西。** 上面那個 github.com 網址只是「說明書放的位置」，AI 自己會去讀。

**② 開一個新對話**
開一個**新對話**就好——**App 不用關**。剛裝的指令要在新對話才會載入（它是在「開啟對話的那一刻」才掃描你裝了什麼）。

**③ 個人化 + 畢業演練**
在新對話打 `/agent-setup`（ChatGPT/Codex 打 `$agent-setup`）按 Enter。它會：
1. 訪談你（名字、你在忙什麼、想要什麼樣的夥伴）→ 寫成它的人格；
2. 用一件**你本來要自己做的真事**破冰，讓你看到「叫它做」比「自己做」快；
3. 帶你做一次**畢業演練**——跑 `/retro` 存記憶 → **再開一個新對話**（一樣不用關 App）→ 打 `/relay`，親眼看到新對話認得你、接著把事做下去。

第 3 步是重點：**「它會記得你」用聽的沒有感覺，開一個全新對話、看到它接上，你才會真的開始用。**

## 設定好後，親手試這幾件事（建立「叫它做」的反射）
直接用講的丟給它，挑幾個跑一遍：
- 📥 **找資料 + 存檔**：「幫我找 X 公司最新財報，抓下來存成檔案」
- 📊 **做表**：「把這段資料整理成一張 Excel 表」
- ✍️ **產文件**：「幫我寫一封 email 草稿 / 一份大綱，存成 Word」
- 🗂️ **整理檔案**：「看一下這個資料夾，幫我把檔案分類、重新命名」
- 📄 **讀長檔**：丟一份 PDF 進來 →「幫我摘要成三點」

跑過幾次你就會習慣：有任務先問它，別自己開瀏覽器。

## 設定好之後（Claude 用 `/`，ChatGPT/Codex 用 `$`）
- **開工**覺得它忘了你 → `/relay`
- **收工**想把這段存起來 → `/retro`
- 想再調人設 / 加新指令 → `/agent-setup`
- 想用得更順不被打斷 → Claude：畫面**左下角**（或 `Shift+Tab`）切 **Accept Edits**；Codex：打 `/permissions` 調寬鬆
- 想換更聰明/更快的模型 → Claude：畫面**右下角**切 model；Codex：`/model`（一般選最強的體驗最好）
- 看所有可用指令 → Claude 打 `/`；Codex 打 `/skills`

## 這個 repo 裝了什麼
- `payload/` → 安裝到使用者層家目錄（**Claude=`~/.claude/`、Codex=`~/.codex/`**，每個對話自動載入，與工作資料夾無關）
  - `L0.md`（靈魂/身分/使用者/鐵則，含待填空格）→ 裝成 `CLAUDE.md` 或 `AGENTS.md`
  - `skills/agent-setup/`（裝+調+畢業演練）、`skills/{relay,retro}/`、`agent-memory/INDEX.md`
  - 內容 runtime 中立，用 `{{HOME}}` / `{{L0}}` / `{{CMD}}` 等佔位符；**安裝時由 AI 依自己是哪個 runtime 替換**（單一份內容，不維護兩套）
- `SETUP.md` — 給 AI 讀的安裝腳本（自行判斷 runtime → 替換佔位符 → 安裝；個人化交給下一個新對話的 agent-setup）

## 維護
改 `payload/` 或 `SETUP.md` → commit & push；使用者下次重貼安裝句即拿到最新。已安裝者的檔案不會自動更新（backlog）。
